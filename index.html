Artefacts

Visionneuse publique des artefacts publiés avec Tadaaa : documents SDUI déclaratifs (JSON, composants web Concorde d'une liste blanche, jamais de code exécutable) affichés en pleine page à https://artifacts.tadaaa.space/<slug>.

Les agents IA publient et mettent à jour les artefacts via le serveur MCP Tadaaa (https://api.tadaaa.space/mcp, OAuth 2.1). Un artefact public se lit en JSON via GET https://api.tadaaa.space/api/public/artifacts/{slug}. Gratuit, open source (MIT).
