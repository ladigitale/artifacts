# Pricing

> Artefacts is free. No paid plan, no price, no credit card.

**Artefacts is free.** There is no paid plan, no price tier and no cost to read or publish artefacts.

| Plan | Price | What you get |
|---|---|---|
| Free | 0 € | Read any public artefact without an account. With a free Tadaaa account: publish, update and share artefacts through the MCP server, datasets shared with reader / writer members. |
| Self-hosted | 0 € (MIT licence) | Run the viewer ([ladigitale/artifacts](https://github.com/ladigitale/artifacts)) and the Tadaaa API ([ladigitale/tadaaa](https://github.com/ladigitale/tadaaa)) on your own server. |

Limits on the hosted service: per-account storage quota and per-IP rate limits on the public API, set by the operator to fit server capacity. No sandbox plan: use a dedicated dataset for tests.

Create an account: [app.tadaaa.space](https://app.tadaaa.space)
