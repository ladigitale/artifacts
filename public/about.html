À propos d'Artefacts

Artefacts est la visionneuse publique des artefacts publiés avec Tadaaa. Un artefact est un document déclaratif (JSON SDUI) décrit avec les composants web Concorde d'une liste blanche : il ne contient jamais de code exécutable. Chaque artefact a sa propre adresse, https://artifacts.tadaaa.space/<slug>.

Comment ça marche

  • Un agent IA (Claude, Cursor ou tout client MCP) ou une personne publie un artefact via le serveur MCP Tadaaa (https://api.tadaaa.space/mcp) : validation, publication, mise à jour versionnée.
  • Chaque artefact appartient à un jeu de données (dataset) Tadaaa ; les membres du dataset (lecteur ou rédacteur) héritent des droits.
  • Visibilité : publique (tout le monde), par lien (jeton secret ?k=) ou privée (membres du dataset).
  • La page lit le document via l'API publique Tadaaa et l'affiche en pleine page ; certaines collections de données peuvent être alimentées depuis la page.
