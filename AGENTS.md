# Artefacts — agents

SPA Lit + Concorde (modèle Ceintures / belts).

- DataProvider `get` / `set` — pas de `sonic-fetch` / `PublisherManager`
- `@handle` + `DataProviderKey` — pas `@onAssign`
- Imports courts `@supersoniks/concorde/...`
- Port 3300 · appId `artifacts`
- API : Tadaaa `/api/artifacts` + `/api/public/artifacts/{slug}`
- Concorde **classique** (5.x). Tout le créatif/interactif (3d, shader, webgpu, hugging-face-infer, interactive, sound, audio, media, physics, controller, device, animation, p2p) vient de `@supersoniks/creative-stack`, y compris les compléments de `sonic-if` / `sonic-value` et les fonctions JSONata (`$cosine`, `$rankBySimilarity`, `$mediaUrl` via l'alias `jsonata` de `vite.config.mts`). Pas de branche visual-stack.
- Scènes pilotées par le format `nodes` de creative-stack (`src/shared/nodes.ts`) : `sonic-physics nodes-plane` / `sonic-timeline nodes-out` / un store écrivent `nodes`, `sonic-3d`, `sonic-stage` (éléments SDUI) et `sonic-2d` (PixiJS, `pixi.js` en dépendance ; chargé à la demande comme three) le lisent. Pixi tourne sous la CSP de prod grâce à `pixi.js/unsafe-eval` importé par l'addon. `sonic-2d` limité à 4 par document (`sdui-guard.ts`). `sonic-skeleton` (addon animation) écrit `nodes`, `bones` et `rest` ; un `sonic-sprite shape="mesh"` déforme une image entre les os. Photo posable : `sonic-frame-sync hold`/`control` fige l'image, `sonic-puppet` (creative-stack, addon animation) mesure le squelette sur la personne (articulations de `sonic-pose-tracker`, rien de préréglé) et publie `rest` (avec `radius` par os) et `bones` : un `sonic-sprite shape="mesh" source="#personne"` (`sonic-mask-replace effect="cutout"`) se déforme par poids sans trou (`mode="pieces"` : pièces rigides en `sprites`) ; limité à 1 par document (`sdui-guard.ts`, même liste que le validateur Tadaaa) ; l'ancienne recette `sonic-skeleton fit rest="pose" angle-add-from` reste valable pour un squelette préréglé, `sonic-mask-replace effect="fill"` retire la personne du décor ; `sonic-sprite blend` (screen/add/multiply) et `sonic-2d` lisible comme texture par `sonic-shader channelN="#id"` ; shader `smoke` (bibliothèque). Suivi ML : `sonic-segmenter` (multi-classes), `sonic-click-segmenter` et `sonic-image-embedder` sont limités à 1 par document (`sdui-guard.ts`) et partagent la politique de modèles de `vision-config.ts`. Smoke : `node scripts/smoke-scenes.mjs` (fixtures `scene-2d`, `scene-dom`).
- Mondes en primitives : clé `monde` (DP ou attribut) de `sonic-3d` et `sonic-2d` (creative-stack, `src/shared/monde`, doc `3d/monde.md`) — modèles articulés, clips, textures procédurales, placement ; même JSON et mêmes `nodes` dans les deux rendus (`clip`, `clipSpeed`, `clipT`, `roles` en plus du format partagé). Rien à charger en plus : les addons 3d / 2d habituels.
- Objets du quotidien dans `sonic-procgen` (creative-stack, addon procgen, doc `procgen.md`) : générateurs `ball` (22 ballons à taille réelle, `affords` et `physics` dans la sélection), `seat` (22 assises, ancres `sit.N` ; acteur `{target: "<id>.sit.N", action: "sit"}`) et `assembly` (objet sur mesure en pièces box/rod/tube/lathe/blob, sans évaluation de code) ; rôles de couleur `red`…`black` ; scène `aire-de-jeux`. Rien à charger en plus.
- `sonic-p2p` (salons) : le viewer impose `artifact` (slug), `api` (origine Tadaaa, `loadApiBaseUrl()`) et `link-token` à chaque nœud, y compris dans `library` (`src/app/room-context.ts`, appelé dans `artifact-viewer.ts` avant `transformDocument`) ; les valeurs du document sont ignorées. Aperçu de l'atelier : `artifact` et `api` vides, aucun appel réseau.
- Smoke tests : `CHROME_PATH=…/chrome node scripts/smoke-<nom>.mjs` après `VITE_API_BASE_URL=http://localhost:4455 yarn build`.
- Embed : `public/embed.js` + `src/embed/` (build `LIB_NAME=embed`, préfixe `afx`). Ne jamais lire `location` / `history` en mode `embedded` du viewer. Addons creative-stack : à la demande via `src/app/addons.ts` (pas d'import statique hors `interactive`).
- Vues A2UI : `views[].a2ui` (messages A2UI v0.9, exclusif avec `root`) rendus par `@ladigitale/agent-stack` (`src/app/components/artifact-a2ui-view.ts`) ; `views[].actionStore` reçoit les actions (`{type: name, payload: {...context, surfaceId, sourceComponentId}}`). Libraries `a2ui:*` / `chat:*` d'agent-stack ajoutées à toutes les vues SDUI (`withAgentLibraries`). Smoke : `node scripts/smoke-a2ui.mjs`.
- Atelier : `/admin/atelier` et `/admin/{slug}/atelier` (`src/app/components/artifact-atelier-page.ts`) — `sonic-chat` (agent-stack) sur `POST {api}/agent/artifacts/run` (Tadaaa, profil `artifacts`), aperçu par `artifact-viewer` en mode `previewDocument` (aucun appel API, pas de sinks) alimenté par l'événement `artifact-preview`. Smoke : `node scripts/smoke-atelier-chat.mjs`.
- UI admin : coque `src/app/components/artifact-shell.ts` (barre haute + menu compte sur bureau, onglets en bas sur mobile ; l'atelier est plein cadre) et couche commune `src/app/styles/ui.ts` (échelle d'espacement base 4, échelle typo, `.page-head`, `.panel`, `.pill`, `.notice`, `.empty`, `.field`…). Tout passe par les variables `--sc-*` : aucune couleur en dur, les 14 thèmes Tadaaa restent lisibles. Les choix de filtre / visibilité ne passent plus par des `sonic-button unique` liés au formulaire (ils écrivaient `null` dans le DataProvider au montage) : boutons natifs `role="radio"` / `menuitemradio` + `set(...)`. Le sélecteur de thème (`artifact-theme-switcher`) liste les 14 thèmes et enregistre le choix sur le compte (`PUT /api/appearance`).
- `sonic-button` : `type` est une **couleur** (`default`, `primary`, `neutral`, `warning`, `danger`, `success`, `info`), jamais `"button"` (valeur ignorée : un bouton `ghost`/`outline` devient presque invisible). Bouton d'icône seule : `type="default" variant="ghost" shape="circle"`. `variant` : `default|ghost|outline|unstyled|link` ; `size` : `2xs…2xl|inherit` ; `shape` : `default|circle|square|block`.
- Listes SDUI : `sonic-list` + `<template>` (ligne), `data-bind` + `::prop` dans la ligne. Concorde n'observe `data-bind` que dans le document et les shadow roots de ses composants : `artifact-viewer` observe le sien (`createRenderRoot`). Garde des liaisons dans `sdui-guard.ts` (`bindingError` : pas de `::…-html`, `::on…`, `::style`, formats `|…` / `js|…`, URL liée = https littéral en tête), mêmes règles que le validateur de l'API ; `Format.js` (eval de data-bind) neutralisé dans `concorde-sdui-runtime.ts`.
- Carte : addon `map` de creative-stack (`sonic-map`, MapLibre 5, dépendance `maplibre-gl` chargée à la demande comme three).
- Synchro image/effet d'un tracker ML : `sonic-frame-sync` (creative-stack, addon media) affiche l'image exacte analysée (les trackers publient `frameSeq`/`latencyMs`). Doc agent : `media.md` (modes sync / delay-ms / live), `shader.md` (recette visage + shader), `vision.md`. Limité à 2 par document (`sdui-guard.ts`).
- Graphiques : `sonic-plot` (creative-stack, addon plot) — SVG aux tokens `--sc-*`, données par `data-provider`, descripteur validé (formats nommés, pas de fonction). Smoke : `node scripts/smoke-plot.mjs` (fixture `plot`).
- Formes vectorielles : `sonic-vector-op` (union, intersect, difference, xor, offset, simplify, round, fit, clip sur chemins SVG) et `sonic-vector-library` (creative-stack, addon vector). Smoke : `node scripts/smoke-vector.mjs` (fixture `vector`).
- Image vers vecteurs : `sonic-vectorize` (creative-stack, addon vectorize) — source `#id` d'une source d'images, couches SVG publiées dans l'état. Smoke : `node scripts/smoke-vectorize.mjs` (fixture `vectorize`).
- Compter des objets : `sonic-blobs` (creative-stack, addon blobs) — source `#id` d'une source d'images, éclairage aplati + seuil d'Otsu + composantes connexes + séparation des objets collés ; `auto` compte chaque nouvelle image (en continu sur une caméra), `params` règle en direct ; état `{count, estimate, blobs[], overlay.url}`, aperçu = marqueurs à superposer à l'image (même `fit`). Smoke : `node scripts/smoke-blobs.mjs` (fixture `blobs`).
- Lecture de texte : `sonic-ocr` (creative-stack, addon ocr) — Tesseract.js épinglé servi par jsDelivr (script avec empreinte d'intégrité, worker, noyau WebAssembly, langue). Smoke : `node scripts/smoke-ocr.mjs` (fixture `ocr` ; le réseau jsDelivr est simulé depuis les paquets npm dans `OCR_PKG`, défaut `/tmp/ocr-pkg` : `npm i tesseract.js@7.0.0 @tesseract.js-data/eng`).
- Pantin articulé : `sonic-ragdoll` (enfant de `sonic-physics`) — os rigides en corps reliés par des pivots à limites, pose publiée au format `sonic-skeleton` (`nodes-out`). Smoke : `node scripts/smoke-ragdoll.mjs` (fixture `ragdoll`).
- Peinture : `sonic-paint` (creative-stack, addon paint) — toile à pinceau doux, gomme, annuler / rétablir ; source d'images `#id` pour `sonic-shader`. Smoke : `node scripts/smoke-paint.mjs` (fixture `paint`).
- Dessin vectoriel à zoom infini : `sonic-sketch` (creative-stack, addon sketch) — zoom / déplacement infinis, pointes personnalisées (`tip`, `tip-from`), gomme de traits, export SVG. Smoke : `node scripts/smoke-sketch.mjs` (fixture `sketch`).
- Prédiction : `sonic-train` (entraîne dans le navigateur à partir d'un CSV ou de lignes : tâche détectée, courbe d'apprentissage, métriques, importance des variables) et `sonic-predict` (creative-stack, addon predict). Smoke : `node scripts/smoke-predict.mjs` (fixture `predict`).
- Défilement : `sonic-scroll` (creative-stack, addon scroll) — position, avancement, vitesse et avancement de chaque section en DataProvider, valeurs lissées pour `sonic-timeline time-source`. Smoke : `node scripts/smoke-scroll.mjs` (fixture `scroll`).
- Curseur : `sonic-cursor` (creative-stack, addon cursor) — position, vitesse, appui et élément survolé (`data-cursor`) en DataProvider, suiveur optionnel, effet magnétique. Smoke : `node scripts/smoke-cursor.mjs` (fixture `cursor`).
- Texte cinétique : `sonic-split-text` (creative-stack, addon text) — découpe en caractères, mots ou lignes, révélation décalée pilotée par un avancement 0..1 (défilement, lecture auto). Smoke : `node scripts/smoke-split-text.mjs` (fixture `split-text`).
- Polices fournies : `fontFiles` (assets `.woff2`, polices variables comprises) appliqué par `src/app/doc-fonts.ts` via l'API FontFace. Smoke : `node scripts/smoke-font-files.mjs` (fixture `font-files`).
- Transitions entre vues : `viewTransition` (fade, slide, zoom) du document, API View Transitions, géré par `setView` dans `artifact-viewer.ts` et `src/css/app.css`. Smoke : `node scripts/smoke-view-transition.mjs` (fixture `view-transition`).
- Détourage : `sonic-segment-anything` (creative-stack, addon hugging-face-infer, SAM 2) — raccourci `sam2-tiny` (`engine: "sam"`) dans `src/app/hf-config.ts`, 1 par document (`sdui-guard.ts`). Smoke : `node scripts/smoke-segment-anything.mjs` (fixture `segment-anything` ; Transformers.js simulé au niveau réseau, le vrai modèle n'est pas exécuté).
